# 🌤️ Weather App

This is my first web development project — a simple and modern Weather App that I built while learning HTML, CSS, and JavaScript.

I wanted to create something practical where I could learn how APIs work, handle real-time data, and build a responsive website from scratch.

## 🌐 Live Demo

🔗 **Live Website:** [https://weather-app-bice-tau-68.vercel.app/]


## ✨ What Can It Do?

- Search for any city and check its current weather
- Get city suggestions while typing
- See the current temperature and weather condition
- View humidity, wind speed, pressure, visibility, UV index, and cloud coverage
- Display different weather icons depending on the conditions
- Show a different experience for day and night
- Responsive design for mobile, tablet, and desktop
- Glassmorphism-style user interface
- Loading and error messages

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- WeatherAPI
